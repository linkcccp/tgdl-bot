## docfx 侧边栏 TOC 内联修复

- **时间**: 2026-09-04
- **执行 agent**: developer
- **改动内容**: 在 `TGBot.Docfx/Program.cs` 新增 `InlineSidetoc` 方法，docfx build 完成后自动读取 `docs/api/toc.html` 的导航结构，内联注入每个 API 页面的 `<div id="sidetoc">` 占位符。119 个 API 页面全部更新。
- **原因**: docfx default 模板依赖 JavaScript AJAX 加载侧边栏 TOC，通过 `file://` 协议打开时被浏览器 CORS 阻止，导致侧边栏始终为空。
- **结果**: 所有 API 页面侧边栏现在包含完整的命名空间+类导航链接，无需 AJAX 加载。`dotnet build` 0 警告。
- **commit**: `f1e7876` fix: 内联 docfx API 页面侧边栏 TOC，解决 file:// 下 AJAX 加载失败导致侧边栏为空
