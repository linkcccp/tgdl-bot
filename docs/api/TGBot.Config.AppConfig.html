Class AppConfig

应用配置模型，由 ConfigParser 从 config.conf 解析得到， 装配期再经 OverlayApplier overlay 合并（record 的 with 语义， init-only 不可变，运行期不可热改）。

所有路径均为绝对路径（在加载阶段展开）。
