Class OverlayStore

overlay 持久化存储：StateDir/config-overlay.json（键 → 字符串值）与 StateDir/access-overlay.json（bot 白名单追加列表）。

与安装配置（config.conf）物理隔离、互不覆盖；原子写（临时文件 + rename）+ 锁保证并发安全； 两文件分开存储避免互锁。entrypoint 不触碰这些文件，tgdl-data 卷持久，pull 重建不丢。
