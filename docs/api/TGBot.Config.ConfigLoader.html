Class ConfigLoader

负责定位并读取 config.conf。

查找顺序：--config <path> 参数 → 环境变量 TGDL_CONFIG → 与程序二进制同目录 → 当前工作目录。若仍找不到则抛出 ConfigLoadException。 错误消息为中英双行并列（启动期无用户上下文）。
