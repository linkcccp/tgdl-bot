Class OverlayApplier

将 config-overlay.json 显式逐键覆盖到 AppConfig（with 语义，禁用反射，编译期安全）。

仅覆盖 MutableKeys 白名单键；BotToken、安装白名单两键与 StateDir 拒绝 （StateDir 为安装锁键：状态目录不应由 bot 远程改动，overlay 自身始终以 config.conf 推导的目录读取）； 非法值/未知键跳过并产生警告（overlay 由 /config 经 ValidateValue(string, string) 写入， 手工改动时防御）。
