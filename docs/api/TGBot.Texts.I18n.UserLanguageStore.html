Class UserLanguageStore

per-user 语言显式选择存储：<StateDir>/languages.json（userId → 语言）。

仅存储显式选择（/language 或首次弹窗选择），auto/映射结果不落盘； 内存 ConcurrentDictionary<TKey, TValue> + 原子写（临时文件 + rename）保证并发安全。
