Class LanguageCatalog

语言目录注册中心：内置 en/zh 嵌入式资源 + 运行时注册扩展语言。

开发者可通过 Register(string, IReadOnlyDictionary<string, string>) 一行注册新语言（或提 PR 增加嵌入式资源）； 注册在 I18nService 构造时合并生效（注册内容覆盖内置键）。
