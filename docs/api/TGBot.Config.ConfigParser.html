Class ConfigParser

config.conf 解析器。

格式：每行 键 = 值，支持 #/; 注释、空行与 [section] 段头。 解析失败抛出 ConfigParseException，消息为**中英双行并列**（启动期无用户上下文，双行最稳妥）。

值校验单点：ValidateValue(string, string)，/config set 与启动解析共用，禁止在其他模块重复实现规则。
