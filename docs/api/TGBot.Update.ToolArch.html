Class ToolArch

工具二进制下载地址的架构映射（/update 运行期按进程架构选择对应架构的官方资产）。

镜像按架构构建（seed-bin 与镜像一致），唯一在运行期下载外部二进制的是 /update， 因此只有这里需要感知架构。URL/资产名均为第三方官方命名，保留原样并在注释中注明对应关系 （amd64 即 x64、aarch64 即 arm64）。
