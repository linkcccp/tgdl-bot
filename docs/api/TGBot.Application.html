Namespace TGBot.Application

Classes

AppHost

应用宿主：解析命令行参数、加载配置、装配各模块并启动 Bot 服务。

支持 --smoke-test 自检模式（验证配置与模块装配并输出内存占用，不连接网络）。

BotService

Bot 服务：Long Polling 主循环，带异常兜底与重启退避。

CommandHandler

指令处理器：/update、/status、/help、/cookie、/cookies。

DownloadCoordinator

下载协调器：负责排队、并发控制、模式（视频/音频）、重试、进度通知与临时文件清理。

MessageRouter

消息路由器：访问控制 → 指令 / 文件（cookies 上传）/ 链接校验与模式选择 → 下载任务入队。
