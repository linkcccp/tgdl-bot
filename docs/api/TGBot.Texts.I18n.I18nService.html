Class I18nService

国际化服务实现：加载嵌入式 en.json/zh.json 与 Register(string, IReadOnlyDictionary<string, string>) 注册的语言，提供缺键回退（en → 键名）与占位符格式化。

数字格式化在 InvariantGlobalization 下固定为 invariant，占位符语义确定。
