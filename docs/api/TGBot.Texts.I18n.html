Namespace TGBot.Texts.I18n

Classes

BotLanguageExtensions

BotLanguage 与语言代码字符串之间的映射辅助。

I18nService

国际化服务实现：加载嵌入式 en.json/zh.json 与 Register(string, IReadOnlyDictionary<string, string>) 注册的语言，提供缺键回退（en → 键名）与占位符格式化。

数字格式化在 InvariantGlobalization 下固定为 invariant，占位符语义确定。

LanguageCatalog

语言目录注册中心：内置 en/zh 嵌入式资源 + 运行时注册扩展语言。

开发者可通过 Register(string, IReadOnlyDictionary<string, string>) 一行注册新语言（或提 PR 增加嵌入式资源）； 注册在 I18nService 构造时合并生效（注册内容覆盖内置键）。

UserLanguageResolver

用户语言解析器：按设计文档 §2.3 的解析链（高→低）决定消息语言：

  1. 私聊用户显式选择（UserLanguageStore）。
  2. Telegram language_code 前缀映射（经 NormalizeLanguageCode(string?)）。
  3. 全局默认语言（auto 时跳过本步）。
  4. 内建 fallback：en。

群组/频道消息不查用户存储，直接走全局默认 → fallback。

UserLanguageStore

per-user 语言显式选择存储：<StateDir>/languages.json（userId → 语言）。

仅存储显式选择（/language 或首次弹窗选择），auto/映射结果不落盘； 内存 ConcurrentDictionary<TKey, TValue> + 原子写（临时文件 + rename）保证并发安全。

Interfaces

II18n

国际化文本服务：按语言与键渲染文案（支持 {0} 占位符格式化）。

语言随消息显式传播（InboundMessage.Language），不依赖隐式上下文。

Enums

BotLanguage

Bot 支持的语言枚举（内置语言集；注册语言不经此枚举）。
