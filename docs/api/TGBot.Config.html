Namespace TGBot.Config

Classes

AppConfig

应用配置模型，由 ConfigParser 从 config.conf 解析得到， 装配期再经 OverlayApplier overlay 合并（record 的 with 语义， init-only 不可变，运行期不可热改）。

所有路径均为绝对路径（在加载阶段展开）。

ConfigLoadException

配置文件加载失败异常（文件不存在或不可读）。

ConfigLoader

负责定位并读取 config.conf。

查找顺序：--config <path> 参数 → 环境变量 TGDL_CONFIG → 与程序二进制同目录 → 当前工作目录。若仍找不到则抛出 ConfigLoadException。 错误消息为中英双行并列（启动期无用户上下文）。

ConfigParseException

配置解析错误。消息为面向用户的中文提示，不含内部实现细节。

ConfigParseResult

解析结果，包含配置对象、解析警告与配置文件原始键值（供 /config list 标注来源）。

ConfigParser

config.conf 解析器。

格式：每行 键 = 值，支持 #/; 注释、空行与 [section] 段头。 解析失败抛出 ConfigParseException，消息为**中英双行并列**（启动期无用户上下文，双行最稳妥）。

值校验单点：ValidateValue(string, string)，/config set 与启动解析共用，禁止在其他模块重复实现规则。
