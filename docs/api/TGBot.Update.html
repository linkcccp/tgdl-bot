Namespace TGBot.Update

Classes

AtomicFileReplacer

原子文件替换器：先写临时文件再原子替换目标，失败时回滚旧版本。

BinaryVersionParser

从二进制输出文本中解析版本号（纯函数，便于单元测试）。

FfmpegToolSource

ffmpeg 官方静态构建源（johnvansickle.com）。

选择理由：官方维护的静态构建，无需 root 权限即可安装到非 root 运行目录、 支持原子替换与回滚，且版本通常领先 Debian apt 仓库；apt 需要 root 且版本较旧。

ProcessOutput

进程运行结果。

SystemProcessRunner

基于 Process 的真实进程运行器。

ToolUpdateResult

单个工具的更新结果。

ToolVersion

工具版本模型（yt-dlp/ffmpeg），支持数值化比较。

UpdateException

更新失败异常。

UpdateReport

整体更新报告。

Updater

默认更新器：对比本地/最新版本，必要时下载新二进制并原子替换，失败自动回滚。

UriVersionParser

从远端响应中解析最新版本号（纯函数，便于单元测试）。

YtDlpToolSource

yt-dlp 官方最新版源（GitHub releases）。

Interfaces

IToolSource

工具最新版本源抽象（用于发现最新版本并下载二进制）。

IUpdater

更新器抽象。

Enums

ToolUpdateStatus

单个工具更新的状态。
