Class FfmpegVersionMarker

ffmpeg autobuild 版本 marker 文件读写。

BtbN master 二进制的 ffmpeg -version 输出 git 提交计数（如 N-118503）， 与远端的 autobuild 日期版本（如 2026.08.17.13.29.26）标度不同，无法直接比较； 更新成功后把安装的 autobuild 时间写入 <installPath>.autobuild， 比较时优先读 marker 保持同标度，"已是最新"短路语义不变。
