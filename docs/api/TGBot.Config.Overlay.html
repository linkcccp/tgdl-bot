Namespace TGBot.Config.Overlay

Classes

AccessEntry

合并后的白名单条目（带来源标注）。

AccessListMerge

安装配置白名单 ∪ overlay 追加列表的合并器：去重（config 来源优先标注）、升序输出。

仅支持追加：config 来源成员不可删除（/access del 时提示），overlay 来源可删。

AccessListMergeResult

合并结果：带来源标注的列表 + 去重后的 ID 集合（供 AccessControlService 使用）。

AccessOverlayData

access-overlay.json 内容：bot 独立维护的白名单追加列表（与安装配置物理隔离）。

OverlayApplier

将 config-overlay.json 显式逐键覆盖到 AppConfig（with 语义，禁用反射，编译期安全）。

仅覆盖 MutableKeys 白名单键；BotToken、安装白名单两键与 StateDir 拒绝 （StateDir 为安装锁键：状态目录不应由 bot 远程改动，overlay 自身始终以 config.conf 推导的目录读取）； 非法值/未知键跳过并产生警告（overlay 由 /config 经 ValidateValue(string, string) 写入， 手工改动时防御）。

OverlayStore

overlay 持久化存储：StateDir/config-overlay.json（键 → 字符串值）与 StateDir/access-overlay.json（bot 白名单追加列表）。

与安装配置（config.conf）物理隔离、互不覆盖；原子写（临时文件 + rename）+ 锁保证并发安全； 两文件分开存储避免互锁。entrypoint 不触碰这些文件，tgdl-data 卷持久，pull 重建不丢。

PendingNotify

重启后待发送的通知（/config、/access 变更后由新进程消费）。

PendingNotifyStore

重启通知存储：StateDir/pending-notify.json。

防重复：启动期先 rename 为 .sending（原子认领，进程崩溃也不重发）再发送， 成功后删除；失败保留并递增 MaxAttempts，超过上限丢弃并记录日志。

写入为同步原子写（临时文件 + rename）——调用方必须保证在进程退出前完成（设计遗留问题 5）。
