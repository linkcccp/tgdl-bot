Class UserTexts

面向 Telegram 用户的文案资源键容器（中英双语，实际文案见 Texts/I18n/Resources）。

i18n 迁移后本类仅承载键名常量（消除魔法字符串）；实际文案由 Get(string, string, params object[]) 按消息语言渲染，键缺失回退 en，再缺失回退键名本身。

所有文案均不含内部实现细节（堆栈、路径、配置值等），遵循零信任原则。
