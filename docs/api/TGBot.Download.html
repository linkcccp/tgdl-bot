Namespace TGBot.Download

Classes

DownloadException

下载失败异常。

DownloadGate

下载并发闸门：普通下载占 1 个槽位，自更新占满全部槽位， 从而实现「更新与下载互斥、下载之间并发受限」。

DownloadOptions

单个下载任务的运行参数快照。

DownloadProgress

下载进度信息。

DownloadedMedia

下载成功的媒体文件信息。

JobRegistry

下载任务注册表：跟踪运行/排队任务数量，并对已受理的 URL 去重。

YtDlpArgumentBuilder

构建 yt-dlp 命令行参数（纯函数，便于单元测试）。

所有参数通过 ArgumentList 传递， 不经过 shell，从根本上杜绝命令注入。

YtDlpDownloader

通过 Start() 调用系统安装的 yt-dlp 二进制实现下载。

不内嵌 yt-dlp/ffmpeg，使用 ArgumentList 避免 shell 注入。

YtDlpOutputParser

yt-dlp 标准输出/错误输出解析器（纯函数，便于单元测试）。

YtDlpOutputParser.MetaLine

元数据行解析结果。

Interfaces

下载器抽象，负责调用外部 yt-dlp 进程完成下载。

Enums

DownloadFailureReason

下载失败原因分类，用于向用户给出准确提示而不泄露内部细节。
